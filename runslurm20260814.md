### 3.1 `slurm.use_srun` — new knob (`src/omnifed/slurm_launcher.py`, `conf/base.yaml`)

`true` (default) emits the existing srun script unchanged. `false` fans the ranks
out as background processes on the single allocated node, exporting the `SLURM_*`
variables `slurm_worker` reads, and refuses multi-node runs with a clear error.

```python
    job_name: str = "omnifed"
    # False = fan the tasks out with plain background processes on the single
    # allocated node instead of ``srun`` (sites where step launch is unavailable).
    use_srun: bool = True
```

```python
        if not sconf.use_srun:
            lines += SlurmOnlyLauncher._local_fanout_lines(sconf, pyexe, cfg_dir, payload_b64)
            SlurmOnlyLauncher._write_and_submit(sconf, "\n".join(lines) + "\n")
            return
```

```python
    @staticmethod
    def _local_fanout_lines(
        sconf: SlurmConfig, pyexe: str, cfg_dir: str, payload_b64: str
    ) -> List[str]:
        """
        Task launch without ``srun``: one background process per rank on the single
        allocated node, exporting the ``SLURM_*`` variables slurm_worker reads.

        Only valid for a single-node allocation — srun is what crosses nodes.
        """
        ntasks = sconf.ntasks or (sconf.nodes * sconf.ntasks_per_node)
        if sconf.nodes > 1 or ntasks > sconf.ntasks_per_node:
            raise ValueError(
                "slurm.use_srun=false launches tasks on one node only, but this run needs "
                f"ntasks={ntasks} across nodes={sconf.nodes} (ntasks_per_node={sconf.ntasks_per_node}). "
                "Fit the run on a single node or re-enable slurm.use_srun."
            )

        rank_log_dir = os.path.dirname(sconf.stdout) if sconf.stdout else cfg_dir

        return [
            'echo "SLURM_JOB_ID=$SLURM_JOB_ID"',
            'echo "SLURM_NODELIST=$SLURM_NODELIST"',
            'echo "Running on $(hostname)"',
            'echo "PYTHONPATH=$PYTHONPATH"',
            "",
            f"mkdir -p {shlex.quote(cfg_dir)} {shlex.quote(rank_log_dir)}",
            f'export OMNIFED_CFG_B64="{payload_b64}"',
            f'echo "$OMNIFED_CFG_B64" | base64 -d > {shlex.quote(sconf.cfg_json_path)}',
            "",
            # slurm_worker reads MASTER_ADDR when `scontrol` is not callable from
            # wherever the worker python lives (e.g. inside a container).
            'export MASTER_ADDR="${MASTER_ADDR:-$(scontrol show hostnames "$SLURM_JOB_NODELIST" | head -n1)}"',
            f'export OMNIFED_NTASKS={ntasks}',
            'echo "MASTER_ADDR=$MASTER_ADDR ntasks=$OMNIFED_NTASKS"',
            'echo "Using worker python: ${PYEXE:-' + pyexe + '}"',
            "",
            'if [ -n "${ROCR_VISIBLE_DEVICES:-}" ] && [ -z "${HIP_VISIBLE_DEVICES:-}" ]; then',
            '  export HIP_VISIBLE_DEVICES="$ROCR_VISIBLE_DEVICES"',
            "fi",
            "unset ROCR_VISIBLE_DEVICES || true",
            "",
            "pids=()",
            'for r in $(seq 0 $((OMNIFED_NTASKS - 1))); do',
            f'  rank_log="{rank_log_dir}/rank_${{r}}.log"',
            '  echo "[launch] rank=$r -> $rank_log"',
            "  SLURM_PROCID=$r SLURM_LOCALID=$r SLURM_NTASKS=$OMNIFED_NTASKS \\",
            '    ${PYEXE:-' + pyexe + '} -u -m src.omnifed.slurm_worker '
            f'--cfg-json {shlex.quote(sconf.cfg_json_path)} > "$rank_log" 2>&1 &',
            "  pids+=($!)",
            "done",
            "",
            "rc=0",
            'for p in "${pids[@]}"; do wait "$p" || rc=$?; done',
            f'echo "[launch] all ranks exited (rc=$rc); per-rank logs in {rank_log_dir}"',
            'exit "$rc"',
        ]
```

Script writing/submission was factored into a shared `_write_and_submit()` used by
both branches (previously inline at the end of `submit_or_exit`).

### 3.3 Master-address fallback (`src/omnifed/slurm_worker.py`)

`scontrol` is not callable from inside the apptainer image, so the unconditional
call crashed every rank. The batch script exports `MASTER_ADDR` from the node
where `scontrol` *does* work.

```diff

-        ["scontrol", "show", "hostnames", os.environ["SLURM_NODELIST"]],
-        text=True,
-    )
-    return out.strip().splitlines()[0]
+    try:
+        out = subprocess.check_output(
+            ["scontrol", "show", "hostnames", os.environ["SLURM_NODELIST"]],
+            text=True,
+        )
+        return out.strip().splitlines()[0]
+    except Exception as e:
+        # `scontrol` is not always reachable from where the worker python runs
+        # (containers, sites without the Slurm client libs). The batch script
+        # exports MASTER_ADDR from the node where it *is* callable.
+        for env_key in ("MASTER_ADDR", "SLURMD_NODENAME", "HOSTNAME"):
+            host = os.environ.get(env_key)
+            if host:
+                print(
+                    f"[slurm_worker] scontrol unavailable ({e}); "
+                    f"using {env_key}={host} as master address",
+                    flush=True,
+                )
+                return host
+        raise
```

### 3.4 Submitting from inside an allocation (scratchpad wrapper)

`Engine` only submits when `SLURM_JOB_ID` is absent (it assumes a login node), and
`sbatch` exports the OnDemand session's environment into the job. Needed only when
submitting from an OnDemand/interactive session — not from a login shell.

```bash
#!/bin/bash
set -euo pipefail
cd /mnt/vstor/CSE_MSE_RXF131/cradle-members/mds3/txw387/dpfed/OmniFed

unset_args=()
while read -r v; do
  [ "$v" = "SLURM_CONF" ] && continue   # SLURM_CONF locates the controller — keep it
  unset_args+=("-u" "$v")
done < <(env | sed -n 's/^\(SLURM[A-Z_0-9]*\|APPTAINER[A-Z_0-9]*\|SINGULARITY[A-Z_0-9]*\)=.*/\1/p' | sort -u)

exec env "${unset_args[@]}" python -u main.py "$@"
```

## 4. The Slurm configuration

`conf/test_fedavg_centralized_torchdist_pioneer.yaml` — inherits the stock preset
and overrides only Slurm + dataset paths.

```yaml
defaults:
  - test_fedavg_centralized_torchdist
  - _self_

engine:
  mode: slurm
  communication_mode: classic

slurm:
  enabled: true
  partition: gpu
  time: "00:30:00"
  # 4 ranks (rank 0 = server, ranks 1-3 = clients) packed on a single node.
  nodes: 1
  ntasks_per_node: 4
  cpus_per_task: 4
  gres: gpu:4 # one GPU per rank; all 4 visible to the batch script
  gpus_per_node: 0
  gpus_per_task: null
  # The venv's torch is a CUDA 12.8 build with no sm_70 kernels, so the 4xV100
  # nodes (gpu4v100) fail with "no kernel image is available". L40S is sm_89 and
  # has 4 GPUs/node. Other safe features: gpu4090, gpu2h100, dgx.
  constraint: gpul40s
  job_name: omnifed_fedavg_mnist
  use_srun: false

  setup_lines:
    # Submitting from an OnDemand session leaks the container's loader/PATH into
    # the job, which breaks the host apptainer (undefined symbol: seccomp_*).
    - 'unset LD_LIBRARY_PATH LD_PRELOAD PYTHONHOME || true'
    - 'export PATH=/usr/local/bin:/usr/bin:/usr/sbin:/bin'
    - 'export OMP_NUM_THREADS=4'
    # Project venv (python 3.10 + torch) only runs inside the OnDemand image.
    - 'export OMNIFED_SIF=/mnt/vstor/CSE_MSE_RXF131/sdle-ondemand/build_link/apt_cpu.sif'
    - 'export OMNIFED_VENV_PY=/mnt/vstor/CSE_MSE_RXF131/cradle-members/mds3/txw387/dpfed/.venv/bin/python'
    - 'export APPTAINER_BIND=/mnt/vstor,/scratch'
    - 'export PYEXE="apptainer exec --nv $OMNIFED_SIF $OMNIFED_VENV_PY"'
    # scontrol is not callable inside the image; resolve rank 0's host out here.
    - 'export MASTER_ADDR=$(scontrol show hostnames "$SLURM_JOB_NODELIST" | head -n1)'
    - 'echo "[setup] PYEXE=$PYEXE MASTER_ADDR=$MASTER_ADDR"'

# ─────────────────────────────────── Pre-staged MNIST (no download on compute)
datamodule:
  train:
    dataset:
      root: /mnt/vstor/CSE_MSE_RXF131/cradle-members/mds3/txw387/dpfed/data/mnist
      download: false
  eval:
    dataset:
      root: /mnt/vstor/CSE_MSE_RXF131/cradle-members/mds3/txw387/dpfed/data/mnist
      download: false
```

Why each Slurm knob:

| Setting | Value | Reason |
|---|---|---|
| `nodes` / `ntasks_per_node` | `1` / `4` | 4 ranks = 1 server + `topology.num_clients=3`; `use_srun: false` is single-node |
| `gres` | `gpu:4` | one GPU per rank; `gpus_per_task: null` so it doesn't conflict with `--gres` |
| `constraint` | `gpul40s` | sm_89, 4 GPUs/node; avoids the sm_70 V100 nodes |
| `use_srun` | `false` | srun step launch is broken cluster-wide |
| `setup_lines` | apptainer `PYEXE`, `MASTER_ADDR`, loader unset | compute nodes can't run the venv python natively |
| `datamodule.*.dataset.root` | absolute `data/mnist` | torchvision wants the dir *containing* `MNIST/raw` |

The dataset root was verified directly:

- 12 of 13 test modules pass (`python -m unittest tests.<module>`).
  `tests/test_hybrid_global_grpc_compression.py` fails on a protobuf
  gencode 6.31.1 vs runtime 5.29.5 mismatch — **pre-existing**, verified by

  fan-out is added) — `use_srun: false` is single-node only, enforced with an
  explicit error.

  behavior-preserving defaults (`use_srun: true`, Frontier `setup_lines`
  fallback); Frontier runs are unaffected.
